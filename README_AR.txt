Safe AI at Work · صفحة تفاعلية (الحلقة السادسة في سلسلة Claude)

جوه الفولدر:
- index.html : الصفحة (Watch the story ← Safety guide ← Practice: stay safe + الشهادة)
- media/     : الفيديو safe_ai_at_work.mp4
- screens/   : شاشات الجايد والتدريب
- fonts/     : الخطوط

تجربة سريعة على الكمبيوتر:
افتح index.html بـ Chrome أو Edge.

الرفع على GitHub Pages:
1. اعمل Repository جديد (Public).
2. Add file > Upload files: ارفع index.html و README_AR.txt و .nojekyll وفولدر fonts وفولدر screens في Commit واحد.
3. ارفع فولدر media (الفيديو) في Commit لوحده.
4. Settings > Pages > Branch: main > Save. اللينك بيظهر بعد دقيقة أو اتنين.
   (index.html لازم يبقى في أول الريبو، مش جوه فولدر.)
